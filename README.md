# Resume to Portfolio

An open-source platform that helps job seekers turn their experience into a professional online presence. Built by developers, for those seeking their next opportunity.

The goal is to make essential portfolio-building tools free and accessible, while giving students and developers opportunities to contribute to a real-world project.

## Planned features

- Upload a PDF or DOCX resume and use AI-assisted extraction to create a structured profile.
- Edit personal details, experience, skills, education, and projects in one place.
- Publish a portfolio at a shareable public URL and choose from different templates.
- Export the updated profile as a PDF resume.
- Control profile visibility and manage access through user accounts.
- Add an AI-powered digital twin that answers questions using the owner's approved professional information.

## Development phases

1. **MVP:** Resume upload and extraction, profile editing, public portfolios, and PDF export.
2. **Digital twin:** Grounded AI chat, more templates, and customization.
3. **Community and growth:** Community-led improvements, possible custom domains, and scalability enhancements.

## Proposed technology

The proposed stack is Next.js, React, Tailwind CSS, Supabase PostgreSQL and Auth, an LLM API, and Vercel. PostgreSQL with JSONB can hold the structured profile; pgvector may support retrieval for the digital twin later.

## Contributing

Contributions to features, templates, fixes, and documentation are welcome. Contribution guidelines and setup instructions will be added as the project takes shape.

This project is in the planning stage; the features and technology choices above are proposed, not yet implemented.
